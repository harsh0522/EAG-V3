WHAT IS THIS?

An AI agent that turns vague ideas into professional prompts — and grades its own work

When you type a rough idea into ChatGPT, you get mediocre results because the prompt is weak. This tool takes your rough idea and runs it through 4 chained AI agents that write, score, fix, and re-score the prompt automatically. You get a professionally engineered prompt every single time — with a quality report showing exactly what improved.

08 — TOOLS & TECH USED

Every tool in the stack — what it is and why it's there

ToolWhat It Does In This Project
PythonThe programming language — glue that connects all 4 agents together.
PydanticData validation library. Every LLM response is validated against a strict schema — wrong fields crash early, not silently.
httpxHTTP client. Makes the actual web request to call the LLM — like a browser, but in code.
LLM Gateway V2A local server on port 8100. The only door to the AI — all 4 steps call it. Swap Gemini for GPT-4 by changing one line in .env.
Gemini 3.1 Flash LiteGoogle's AI model. The brain behind all 4 agents — builder, evaluator, improver, re-evaluator.
uvModern Python package manager — faster alternative to pip for installing dependencies.
09 — THE KEY DESIGN DECISION

All LLM calls go through one gateway — your app never touches the AI directly

Every single LLM call in all 4 steps goes through gateway_client.py → localhost:8100 → Gemini. This is a real production pattern: if you want to swap Gemini for OpenAI or Claude tomorrow, you change one line in .env and nothing else changes. The 4 agents don't know or care which AI model is running behind the gateway.
